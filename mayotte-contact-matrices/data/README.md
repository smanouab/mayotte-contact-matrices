# Inputs

The three input workbooks are distributed separately. Use paths to your
authorized local copies when invoking the script.

| Input | Workbook supplied with this analysis |
| --- | --- |
| MayCov survey, first worksheet | BDD_FINALE_REDRESS_POND_VF(9).xlsx |
| INSEE 2017 age distribution, first worksheet | Donnees_Commune_INSEE(9).xlsx |
| Daily confirmed cases, first worksheet | SERIE-COVID-Mayotte(1).xlsx |

Individual-level MayCov data are access restricted. Requests are subject to
approval by the responsible institution. Keep the workbooks outside any
public repository. The script writes aggregate outputs and analysis caches
to the selected output directory.
